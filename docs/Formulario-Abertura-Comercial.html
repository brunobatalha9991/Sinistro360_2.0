Formulário de Abertura de Sinistro/Assistência

Preencha, clique em "Exportar PDF" e salve como PDF. Envie o arquivo para a equipe operacional importar no Sinistro360.

Como usar

  1. Preencha os campos abaixo com os dados do caso.
  2. Clique em "Exportar PDF". Na janela de impressão do navegador, escolha o destino "Salvar como PDF" (ou "Microsoft Print to PDF").
  3. Envie o PDF gerado para quem for cadastrar o processo no sistema.
  4. No Sinistro360, em Configurações → Dados, Migração & IA → Importar formulário comercial (PDF), a pessoa envia esse PDF e o sistema pré-preenche o módulo Abertura automaticamente para revisão e criação do processo.
